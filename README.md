# Учет филамента для 3D-печати

> Катушки, AMS-слоты, проекты и печати — с автоматическим списанием граммов,
> подсчётом стоимости (филамент + электроэнергия). Офлайн, Windows.

## Основные преимущества

- **Простая установка** — один exe-файл установщика, и программа работает.
- **Себестоимость за 1 штуку** — с учётом стоимости электричества.
- **Никаких интеграций с принтерами** — данные вводятся вручную, просто
  и быстро.
- **Автоматический учёт** — вручную ничего пересчитывать не надо: база данных
  всё считает сама и сохраняет все передвижения катушек.
- **Запасные катушки** — если основной не хватает, программа сама
  подскажет замену в слот.
- **Отмена печати без потерь** — граммы возвращаются своим катушкам,
  если печать была отменена, всё вернётся на свои места.
- **Офлайн и приватность** — без регистрации и аккаунтов, ничего не
  уходит в интернет, данные — только на вашем компьютере.
- **Экспорт в CSV** — любые таблицы выгружаются файлом для своих отчётов
  (открываются в Excel).

## Возможности

**Оборудование**
- Справочник: **64 модели принтеров** и **13 систем подачи филамента**
  (Anycubic, Bambu Lab, Creality, Elegoo, QIDI, Flashforge, FLSUN
  и другие); производитель и модель — раздельными списками,
  совместимость систем подачи — по официальным данным производителей.
  Нет вашей модели? Типовые позиции «Прочий» и «AMS универсальная»
  (переименовывается под вашу систему подачи).
- Слоты для катушек на принтере и в подключённых системах подачи.
- Часы печати, среднее потребление (Вт) по материалам и тариф
  за кВт·ч — электроэнергия включается в стоимость печати.

**Филамент**
- Склад катушек: поступление (производитель, тип, цвет, вес, цена),
  установка в слоты, возврат, утилизация.
- Остатки на каждой катушке — до сотых грамма, итоги по складу.
- Корректировка фактического веса не искажает заявленный «вес полной
  катушки» — цена за грамм остаётся стабильной.

**Проекты и элементы**
- Проект детализируется до элементов (деталей) с цветами и граммами
  на цвет; многоцветные элементы поддерживаются.
- Статистика по каждому элементу: годные, брак, себестоимость штуки.

**Печати**
- Печать по элементам: граммы считаются из состава проекта, подходящие
  катушки по цвету подставляются сами; или печать «только по весу».
- Арифметика в любом числовом поле: дописали «+10» или «-10» к числу,
  нажали Enter — программа посчитала сама.
- Плановый вес с расшифровкой («75г × 2 = 150г»); общий вес и процент
  прогресса пересчитывают друг друга на лету.
- Завершение печати раньше времени: учитываются годные и бракованные штуки,
  записывается напечатанный вес по цветам, непечатаный остаток возвращается катушкам.
  Вес годных рассчитывается — по спецификации, брак — остаток по среднему распределению.
- Запасные катушки: если основной не хватает — программа предложит
  кандидатов для установки в слот.
- Программа рассчитает примерное время замены катушки, это позволит спланировать день и не гадать когда наступит этот момент.

**Прочее**
- Фильтры.
- Экспорт таблиц в CSV (открывается в Excel).
- Журнал операций.
- Горячие клавиши (вызов программы из любого окна — Ctrl+Alt+P).
- Тёмная тема.
- Корректная работа на нескольких мониторах с разным масштабом.
- Сохранение и загрузка данных: копия базы в один клик, автосохранения
  хранятся в 20 экземплярах.

## Принцип работы

Программа не синхронизируется с принтерами или слайсерами и не управляет печатью.
Учёт ведётся вручную: вы сами фиксируете ключевые события (старт, пауза, продолжение, досрочное завершение) в программе.
На основе этих данных рассчитывается расход филамента и электроэнергии по каждой задаче.
Такой подход даёт точный контроль затрат без необходимости подключать оборудование или настраивать интеграцию.

## Установка

Актуальная версия — **1.2.0** (28.09.2026).

- Скачайте установщик со страницы
  **[Releases](https://github.com/3DVopros/3DFilamentUchet/releases/latest)**
  (файл вида `3DFilamentUchet-1.2.0-setup.exe`) и запустите.
- Windows 10/11. Python и зависимости ставить не нужно.
- Установщик без цифровой подписи, поэтому Windows может предупредить
  про «неизвестного издателя» — нажмите «Подробнее» → «Выполнить
  в любом случае». Программа устанавливается в Program Files, данные
  пользователя — в `%APPDATA%\3DFilamentUchet`.
- Новые версии программа проверяет сама; обновление — скачать новый
  установщик и поставить поверх (данные сохраняются).

## Данные

Всё хранится локально (SQLite, `%APPDATA%\3DFilamentUchet`). Никаких
аккаунтов, облаков и телеметрии — программа полностью офлайн. Резервные
копии: кнопка «Сохранение и загрузка данных» на вкладке «О программе».

## Лицензия

Пробный период — **45 дней** со всеми функциями. Далее — ключ активации
на 1–3 года, активация офлайн, без интернета. Условия — «Лицензионное
соглашение»: принимается во время установки программы — для продолжения
установки нужно с ним согласиться.
