# Учет филамента для 3D-печати

> Катушки, AMS-слоты, проекты и печати — с автоматическим списанием граммов,
> подсчётом стоимости (филамент + электроэнергия). Офлайн, Windows.

## Возможности

- **Оборудование** — принтеры со слотами, подключение AMS (ACE Pro, CFS,
  MMU3, HT), часы печати, тариф кВт·ч.
- **Филамент** — склад / используется / утилизация, остатки до грамма,
  предупреждение нехватки на печать - добавьте запасную.
- **Проекты и элементы** — детали с цветами и граммами на цвет,
  себестоимость штуки.
- **Печати** — по элементам или по весу, многоцветные, запасные катушки, корректировка фактического веса во время замены катушки в середине печати, брак, возврат граммов при удалении, паузы и прогресс по времени.
- **Справочники** (производители, типы, цвета).
- **Экспорт CSV**, фильтры, сортировка, журнал операций, тёмная тема,
  подробная справка внутри программы.

## Установка

Скачать установщик `3DFilamentUchet-1.1.1-setup.exe` со страницы
**[Releases](../../releases)** → запустить → дальше всё автоматически
(установка в Program Files, лицензионное соглашение — в установщике).

- Windows 10/11.
- При запуске установщика SmartScreen может предупредить «неизвестный
  издатель» (нет цифровой подписи): «Подробнее» → «Выполнить в любом
  случае».

## Данные

Всё хранится локально (SQLite, `%APPDATA%\3DFilamentUchet`). Никаких
аккаунтов, облаков и телеметрии — программа полностью офлайн. Резервные
копии: кнопка «Сохранение и загрузка данных» на вкладке «О программе».

## Лицензия

Пробный период — **45 дней** со всеми функциями. Далее — ключ активации
на 1–3 года, активация офлайн, без интернета. Условия — «Лицензионное
соглашение»: оно принимается во время установки программы — для продолжения
установки нужно с ним согласиться.
